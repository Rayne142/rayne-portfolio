项目概览

《泡泡》是一款基于刘慈欣短篇小说《山》改编的 3D 探索解谜游戏，使用 Unreal Engine 5.8 开发。玩家扮演封装着硅基科学家波塞冬博士意识碎片的微型机器人「泡灵」，在深海废墟中苏醒，收集记忆碎片、解开科考站遗迹的谜题，最终把文明的火种传回地心。

项目由 5 人团队开发，我担任主策划 / 项目负责人，负责项目管理与排期、策划案与叙事文案、UE 工程搭建与测试打包、场景后处理与程序化自发光，并主持空间叙事走查。

一、世界观：泡世界与无形岩

宇宙深处有一颗与地球大小相仿的行星，它的地核是空的，形成一个半径约三千公里的球形空洞。在这个空洞中诞生了硅基文明——泡世界：肌肉与骨骼是金属的，大脑是超高集成度芯片，电流和磁场是血液，放射性岩块是食物。这里没有气体、没有液体、没有重力，一切悬浮在空间中。

泡世界的核心矛盾是空间守恒：挖洞不能增大空间，只能改变空间的形状与位置。整个文明史就是一部血腥的空间争夺史——探险派主张向外挖掘，寻找「密度为零的天堂」；保守派主张封死所有通道，避免「无形岩」的诅咒。

当最前沿的探险泡船钻透最后一层岩壁，涌入的不是真空而是液体——硅基生命的电路在液体中瞬间短路，第一批接触者全部丧生。泡世界把这种致命物质命名为「无形岩」。他们后来才发现：头顶那片蓝色的、流动的广阔空间，是一片覆盖整个星球表面的海洋。

泡灵计划与灾难

硅基文明在临近海底的岩床下建立了深海前沿科考站 亚特斯（Arth's Deep），与泡世界物理完全隔离，只有信号塔的电磁数据通道相连。这里最重要的研究是波塞冬博士主持的「泡灵计划」——一种通过一层薄空气泡隔绝海水、借浮力移动的微型机器人，核心能力是意识分裂。

一颗陨石坠落海面，冲击波撼动海底岩床，海水倒灌，亚特斯数分钟内被淹没。波塞冬在最后一刻启动泡灵原型机，将部分意识碎片封入其中，留下最后一道指令：「找到信号塔。点亮它。让地心知道——无形岩之上，还有更广阔的世界。」

二、核心玩法机制

《泡泡》的机制设计围绕「同一个意识，两种体量」展开。海底与亚特斯是慢节奏解谜探索（在逝者的记忆中慢慢走），泡世界则是快节奏追逐潜伏（在活人的追捕中拼命跑）。慢与快、死与生、回忆与当下，两个场景合在一起，才是完整的《泡泡》。

光点系统：正常与异常分离

光点是核心资源与叙事载体，玩法与叙事完全解耦——这一设计让「引导」和「讲故事」互不干扰：

维度正常光点异常光点
玩法作用让泡泡变大 + 加速回能不变大，仅加速回能
体型计算计入体型控制不计入，不影响泡泡大小
叙事内容波塞冬本人的记忆碎片（倒叙主线）其他泡灵留下的数据残片（隐藏暗线）
叙述视角波塞冬第一人称其他泡灵 / 未知来源
使用频率高频，用于主线引导低频，剧情补充

规则怪谈：两套互相矛盾的规则

分散的剧情碎片通过「规则怪谈」形式讲述：正常光点与异常光点的规则互相矛盾，因为写下规则的人立场不同——探险派中也有保守派与激进派。玩家在不同情况下遵循不同规则，会被引向不同结局。

规则主题正常光点（探险派视角）异常光点（其他泡灵视角）
光点的作用「收集光点，让泡泡变大，找到信号塔传递信息。」「向上走，不要回头，去登山。」
信号塔「点亮信号塔，让地心知道真相」「不要进入信号塔，不要让他们发现你！」

体型控制与意识分裂

变大收集正常光点增加体积。浮力增强可上浮到更高处，但体重增加，易碎地形碎得更快
变小分裂子泡使主体体积减小。可通过狭窄通道、压碎地形更慢，但浮力减弱、上浮高度降低
分裂 / 召回F 键从主体分离子泡，可独立移动；再按 F 召回，恢复消耗的体积并保留位置信息
子泡注入子泡靠近应急电源、天线、传输节点时按 F 注入，永久激活该装置且不可召回——机制带有情绪重量

传输节点：泡世界的公共交通

泡世界是 Ø80 m 的开阔空洞，城市之间的暴露区是追逐压力最高的地方。为了让玩家有办法穿越它，我设计了传输节点——它替代了早期方案里的「加速管道」：管道要单独教一次、程序也要单独做一套；而传输节点直接 call back 信号塔已经教过的「主泡注入」，玩家零学习成本，程序也只是复用同一个接口。

设定硅基文明的公共交通设施，散布在城市外的开阔空间中；两个节点之间有固定的传输对应关系
使用方式靠近节点后按 F，将主体注入，瞬间传输到对应节点
策略用途快速穿越开阔空间、甩开追击泡船、到达普通移动到不了的位置
视觉标识发光的柱状装置，顶部有旋转的能量环；已解锁暖光，未解锁冷光

三、场景与关卡设计

四个场景构成一条完整的情绪曲线：从孤独苏醒，到逝者记忆中的解谜，再到活人追捕下的奔逃。技能学习遵循三段式——先体验（无谜题）→ 再使用（谜题）→ 后 call back（复用），最终在泡世界的最终追逐中所有技能一起回收，形成高潮。

场景尺寸移动方式情绪主题时长

海底：无谜题的教学与氛围

海底是开场，也是唯一完全不设谜题的场景。它承担五件事，全部靠环境与阻碍完成，参考《Inside》的无文字引导——不写一句教程文字，也不放 UI 箭头。

功能具体内容
操作教学移动、上浮、加速、光点收集全部在海底完成，用环境和阻碍教会玩家操作
技能体验「变大、上浮」的首次体验放在这里，不设谜题，纯粹让玩家感受「变大了是什么感觉」
环境叙事硅基科学家的金属躯体静默躺在海底、被冲毁的设备、闪烁的应急灯——不用文字，用环境告诉玩家「这里发生过灾难」
氛围铺垫从完全黑暗到逐渐看到废墟轮廓，视觉节奏从小到大；深蓝水体、悬浮颗粒、微弱体积光
路径引导光点的位置自然引导玩家向亚特斯入口移动，不需要 UI 箭头

区域上分三段：苏醒区（完全黑暗，只有泡灵自身微光，可视范围 3–5 m）→ 开放水域（沙地、岩石、水草、漂浮的外部设备残骸、被冲毁的钻探平台）→ 亚特斯入口（巨大的金属结构残骸，入口破裂，海水从裂缝中涌入）。

亚特斯：三个谜题的技能教学链

亚特斯是解谜核心，三个房间各承担一次技能教学，并在情绪上形成「三峰波浪」，谜题 2 为最高点：

  • 谜题 1 · 分裂与压力板（教学）：门前压力板踩上即开门，板上方放一个光点暗示「站这里」。玩家分裂子泡停在压力板上，主体通过——首次通过后子泡自动召回不消耗，降低学习门槛。
  • 谜题 2 · 狭窄通道与子泡注入（情绪高点）：通道宽度由 3 m 线性收窄到 1.5 m，初始体积过不去，形成最清晰的「负面示能」，逼出「分裂变小」。子泡注入装置后不可召回，构成一次永久代价。
  • 谜题 3 · 易碎地形（机制反转）：起点旁注入装置开门并使主体减重，但易碎岩板沿途故意散布引导光点——吃了会变大、地面碎得更快，即「光点是陷阱」。玩家需要主动克制，与谜题 1、2 的「尽量吃 / 必须分裂」形成反转。

信号塔：机制反转与情绪呼吸点

信号塔是亚特斯与泡世界之间的过渡节点，不设谜题——亚特斯的三个谜题已经把玩家压得够紧，这里需要一次呼吸。玩家进入宏大的塔室，光柱向上，中央有传输接口，环境暗示「把主体注入装置」。

它同时承担一次关键的机制反转：此前按 F 都是分裂出子泡，这一次按 F 是把自己整个交出去。过场动画里，意识沿信号塔传输、穿过岩层、向地心坠落；黑屏，泡世界接收站苏醒。

为什么放在这里

「主泡注入」是泡世界传输节点的前置技能。与其在泡世界里再教一次，不如把它放在这个天然的情绪转换点——玩家在不知情的情况下学会了后面要反复用到的能力，到泡世界第一次见到传输节点时，会立刻明白该按什么键。这是全案「技能三段式」里最关键的一次伏笔回收。

泡世界：三城推进与追逐潜伏

泡世界是 Ø80 m 的球形空洞，三座城市建筑群悬浮其中，城市之间是开阔的暴露区，散布着传输节点与漂浮巨岩。这里与海底 / 亚特斯形成彻底的体验反差——那里是慢节奏解谜探索（在逝者的记忆中慢慢走），这里是快节奏追逐潜伏（在活人的追捕中拼命跑）。

推进路径是一条「接收站 → A 城 → B 城 → C 城」的单向链条，城市之间用三段压力递增的追逐连接：

阶段地点连接段压力
苏醒接收站追逐 1（巡逻泡船）教学级
潜伏教学A 城（联络城）追逐 2（追击泡船）中等
能力升级B 城（学术中继城）追逐 3（最终追逐前奏）较高
剧情高潮C 城（纪念碑交付城）最终追逐 → 结局最高

通缉与定位系统

整个泡世界的张力建立在一套「暴露 / 隐藏」的开关上：玩家身处何地，决定了保守派知不知道你在哪。

玩家位置定位状态与保守派反应
城市外开阔空间持续暴露、实时定位。附近保守派泡船收到坐标，全速赶来抓捕
城市建筑群内部信号被建筑结构屏蔽，隐藏。泡船失去精确坐标，仅在城市外围巡逻；但城市内有扫描泡船与固定扫描节点威胁
传输节点内注入传输中无敌；传输完成后出现在目标节点，可能有泡船守候

保守派泡船：四类追逐单位

四类单位按压力阶梯依次解锁，每一类都对应一种新的应对方式：

类型外观与行为出现时机
巡逻泡船小型球形，单眼探照灯，速度中等。固定路线巡逻，发现玩家后呼叫支援并尾随全程
追击泡船流线型长体，尾部双推进器，速度快。收到定位后从远处赶来，直线追击，城市外速度高于玩家追逐 2 及以后
拦截泡船大型方体，前部可展开能量网。在玩家可能的路线上提前部署拦截网追逐 3 及最终追逐
扫描泡船中型圆盘，底部大范围扫描阵列。悬停在城市上空缓慢扫描，被照到即暴露位置并触发警报A 城及以后

关键规则：泡船不进入城市建筑群内部——体积大无法穿行，内部信号被屏蔽也无法定位。被追上会触发 BE2，玩家可从信号塔处继续，同时新增一条异常光点：「不要回头！」失败在这里不是惩罚，而是继续往叙事里加东西。

城市内潜伏机制

要素说明
扫描泡船在城市上空缓慢移动，底部有锥形扫描光束，被照到即暴露。暴露后城市外围泡船封锁出口，扫描泡船集中搜索
固定扫描节点建筑走廊、路口的监控装置，有固定扫描范围与转向规律，需要观察时机通过
隐藏点建筑内的壁龛、管道后方、阴影区，躲入后扫描无法发现，可观察巡逻规律
市民掩护城市中有普通硅基市民流动，混在人群中移动可降低被扫描发现的概率（扫描优先识别异常信号源，人群中的信号被稀释）
被发现后果触发城市封锁：所有出口暂时关闭，扫描泡船集中搜索。玩家需躲入隐藏点等待 30 秒封锁解除，或完成当前阶段任务触发剧情推进

三城分工：同一套机制，三种压力

三座城市共用同一套潜伏机制，靠隐藏方式与融合谜题的差异做出三段递进的体验：

城市隐藏方式融合谜题核心体验
A 城密集建筑窄巷 + 壁龛隐藏，市民掩护较少找到联络点入口 + 子泡注入备用电源潜伏教学，压力低，引导充分
B 城开放广场人群掩护 + 工业区管道隐藏，两种策略切换找到阿基米德实验室 + 三权限节点顺序激活潜伏 + 谜题融合，中等压力，能力升级
C 城破败建筑废墟隐藏 + 信号不稳定区域，探索派接应支援纪念碑探索 + 最终追逐（全技能 call back）剧情高潮 + 最终追逐，最高压力，结局

A 城（联络城）是泡世界入口，也是第一个安全点。密集居民区、低矮建筑、窄巷多，隐藏点丰富而扫描稀疏。融合谜题藏在「居民楼地下管道里的联络点」：玩家要观察扫描规律穿过街道（潜伏）、找到楼栋入口（路径探索）、再用子泡注入打开被电磁锁封死的入口——这是亚特斯的技能在泡世界的第一次复用。离开 A 城进入开阔空间前，联络员会给到 Q 键信号干扰器（短暂屏蔽定位 8 秒）。

B 城（学术中继城）是能力升级段。学术区与工业设施混合——开放广场人多可作掩护，工业区管道多可作隐藏，玩家需要在两种策略之间来回切换。核心谜题是「中继站三权限节点顺序激活」：观察扫描规律 → 分裂子泡注入第一个节点 → 主体移动到第二个位置同时操作子泡，最终拿到传输节点使用权与破解程序。阿基米德也在这里登场，把信号干扰器升级到 12 秒。

C 城（纪念碑交付城）是剧情高潮。旧城区与行政中心混合，破败建筑的信号屏蔽不稳定（某些区域会短暂暴露），行政中心扫描密度最高。流程分四段：旧城区潜伏到纪念碑 → 纪念碑前的矛盾集中呈现 → 最终追逐的全技能 call back → 信息交付结局。碑前那段是全案情绪最重的地方：黑色石碑刻满名字，保守派发言人在全城喇叭里说「每一次向外探索，都有人死在无形岩里」，而阿基米德的通讯插进来——「别听他的。你携带的数据，是无数探险者用命换来的。」

空间设计图纸

为保证「视线—构图—节奏」可验证，我为三个场景建立了统一的坐标系与设计基准（泡灵初始直径 0.8 m 作为全局度量尺），并输出总平面图、楼层平面图与大样剖面，用于白盒校验与团队对齐。

四、结局与自由探索模式

结局：主线交付 + 失败也是叙事

主线结局是「信息交付」：玩家冲入探险者中心高塔顶层，把所有数据交付给泡世界的公共信息网络。数据公开的瞬间，全泡世界的信息终端同时亮起——保守派已无力回天，发言人只在广播里留下一句「……希望你知道自己做了什么。」终章演出后，字幕落下。

失败结局不是「读档重来」。被泡船追上会触发 BE2，玩家可从信号塔处继续，代价是新增一条异常光点：「不要回头！」；在纪念碑之后被保守派逮捕则触发 BE3——「探险派？保守派。」。两者都把失败转化成了叙事增量：玩家不是被踢出游戏，而是多拿到一段别人的立场。

调性：悲壮，但不绝望

《泡泡》的结尾不是皆大欢喜，而是「使命完成，道路仍长」。探险派与保守派的矛盾被完整呈现，却不被解决——保守派妥协了，但没有被说服。这是原著《山》留给故事的态度：探索从未止步，也从不轻松。

通关后：自由探索模式

主线结局后，保守派妥协、警戒解除，游戏自动进入自由探索模式。它是一个纯粹的情绪收束空间，不再有任何压力源：

  • 全城自由通行：A / B / C 三城全部可以自由进入，没有追逐、没有潜伏、没有扫描
  • 城市外自由移动：不再有泡船追捕，玩家可以自由滚动穿越整个泡世界，观察城市之间的空间与漂浮碎岩
  • 纪念碑互动：C 城纪念碑可以靠近查看，每一个名字都能触碰，显示该探险者的简短生平
  • 阿基米德实验室：B 城的实验室开放探索，里面有他的研究笔记与浮力实验装置（彩蛋：潜水艇早期设计图）
  • 接收站回顾：回到起点接收站，工程师会与玩家对话——「波塞冬博士！感谢你对科学事业的付出！」

五、叙事动线：从苏醒到「探索从未止步」

《泡泡》的叙事不靠旁白交代，而是靠玩家自己撞见的两类文本：一类是光点里的记忆碎片，一类是沿路刻下的规则。后者是全案最有意思的设计——正常光点与异常光点会给出互相矛盾的规则，因为写下规则的人分属探险派的保守派与激进派。玩家先照做，再发现两套规则打架，最后得自己判断该信谁。

六、视觉风格与美术方向

整体调性是「压抑中的微光，悲壮中的希望」。海底与亚特斯以深蓝、黑暗、工业废墟为主，情绪压抑；泡世界以暖金、淡蓝、发光城市为主，情绪释放但不欢快。整体色调克制，不使用鲜艳彩色。泡世界的建筑形态参考原著「地核中是失重的，我们的城市就悬浮在那昏暗的空间中……远看去，像一团团发光的云」。

七、技术实现

项目基于 Unreal Engine 5.8，采用 C++ 模块 + 蓝图混合开发。核心玩法由 ABubbleCharacter 与水下变体 ABubbleSwimCharacter 承载：后者通过 BeginPlay 把世界的默认物理体积转换为水体并让角色进入 MOVE_Swimming，实现「同一个 Pawn 丢进任意关卡即成水下游泳者」，与陆上变体互不干扰。

  • 水下手感调参：低 MaxAcceleration + 近零制动形成「软加速与长滑行」；中性浮力（Buoyancy = 1）配合 WaterFriction 控制水阻；冲刺时 FOV 推近，参考 ABZU 的爆发反馈。
  • 体积驱动跳跃：BubbleVolume 作为单一数值源，同时驱动跳跃高度与浮力，使「变大 / 变小」的玩法与表现天然一致。
  • 水体与粒子：UE5 Water 插件 + Niagara 气泡粒子，配合体积雾与水下焦散。
  • 后处理与程序化自发光：为海底 / 亚特斯 / 泡世界各配置一套 Post Process Volume，并用自发光蓝图实现应急灯闪烁、信号塔光柱脉动、传输节点能量环旋转。
  • 工具链：用 Python 脚本完成灰盒灯光、自发光后处理、游泳系统装配与设置校验，减少重复手工操作。
  • 版本管理：Perforce（P4）协同，自建腾讯云部署流程与成员连接指南。

八、MVP 范围取舍：1 个月能做出什么

策划案是完整愿景，但 1 个月的周期装不下它。所以另起了一份 MVP 方案——把内容按 P0 / P1 / P2 切成三档，先保证「能从头玩到尾」，再考虑「好不好看」。核心原则是一句话：先让游戏能玩，再让游戏好玩，最后让游戏好看。

P2：砍掉，以及为什么

这一档其实是整份 MVP 方案里最需要向团队解释的部分——砍东西比做东西难。

砍掉的内容原因
自由探索模式开发量大，且要等所有城市内容完成才有意义。MVP 只做线性主线
BE2 / BE3多结局增加开发与测试成本。被追上改为检查点重生，BE3 后续再加
市民掩护机制需要市民 AI、人群流动、信号稀释计算。潜伏只靠隐藏点 + 观察扫描规律
拦截泡船需要能量网特效与绕行路径设计。P1 阶段用静态障碍物代替
B 城完整设计学术区 + 中继站 + 三权限节点谜题开发量大，压缩为通讯器远程交接
C 城旧城区潜伏信号不稳定、破败建筑隐藏、多区域探索开发量大，纪念碑改为线性场景
高质量美术1 个月不可能做完。用白模 + 基础材质 + 简单灯光，重点验证玩法与节奏
完整音效 / 原创音乐用免费占位素材（水下嗡鸣、电子音、警报声），不做原创音乐与精细音效设计
阿基米德 3D 模型用通讯器语音 / 文字代替，不做 3D 角色与动画
扫描泡船复杂 AI固定路线巡逻即可，不做搜索行为、区域封锁、动态难度调整

如果时间极度紧张，底线是：海底 + 亚特斯三谜题 + 信号塔 + 接收站 + A 城（潜伏 + 联络点）+ 简化结局。B 城、传输节点、纪念碑、最终追逐全部砍掉，A 城联络点直接触发结局。这个版本能验证核心玩法循环，但泡世界体验不完整。

技术风险与应对

MVP 阶段最大的风险都不是「做不出来」，而是「做出来了但不好玩」。所以每条风险都配了一个降级方案：

风险应对方案
分裂后双泡泡控制手感差第 1 周快速验证。备选：子泡不做独立控制，改为「射出」到指定位置后自动停留压板，玩家只控制主体——降低操作复杂度
滚动移动惯性难调第 3 周前 3 天专门调手感。备选：滚动改为「悬浮移动」（与水世界类似，只换材质），牺牲差异化但保证可玩
易碎地形碎裂 + 绕行路径 Bug 多第 2 周重点测试。备选：改为「碎裂后从房间入口重生」，或取消惩罚直接传送到对面
扫描泡船判定不准确光束可视化必须清晰（半透明圆锥 + 颜色变化），被照到有明确反馈（屏幕边缘变红 + 警报声）；判定用简单的距离 + 角度检测，不做复杂遮挡计算
泡船 AI 追击太难或太简单追击泡船速度略高于玩家但转弯半径大，玩家可用障碍物与转弯甩开；被追上不做惩罚，检查点重生降低挫败感
第 4 周 P1 内容做不完按优先级砍：传输节点 > 纪念碑 > 追逐 2 > 最终追逐 > B 城交接点。底线是 A 城出口直接触发结局，保证有头有尾
性能不达标场景小（最大 80×80）、白模 + 基础材质，压力可控；不达标就减少动态光源、关闭体积光、降低粒子效果
UE5 学习成本核心逻辑全部用蓝图实现，不写 C++；第 1 周前 2 天集中学习蓝图基础，遇到问题优先查官方文档

九、设计原则总结

把整份策划案压缩成一张表，就是这十条。它们既是设计时的取舍依据，也是评审时用来判断「这个需求该不该做」的标尺。

原则说明
世界观自洽亚特斯与泡世界物理完全隔离，泡灵是把数据传回去，不是物理回去。海水倒灌只淹亚特斯，泡世界存活——先把这个前提钉死，后面的剧情才不会塌
两个大场景体验反差海底 / 亚特斯是慢节奏解谜探索（在逝者的记忆中慢慢走），泡世界是快节奏追逐潜伏（在活人的追捕中拼命跑）。慢与快、死与生、回忆与当下，合在一起才是完整的《泡泡》
光点玩法叙事解耦正常光点管玩法（体型控制），异常光点管叙事（剧情碎片）。规则怪谈通过两套矛盾规则自然呈现，不需要旁白解释
技能学习三段式每个技能都走「先体验（无谜题）→ 再使用（谜题）→ 后 call back（复用）」。最终追逐让所有技能一起回收，形成高潮
谜题难度成波浪亚特斯三个谜题：谜题 1 教学分裂压板，谜题 2 情绪高点（窄道 + 子泡注入），谜题 3 机制反转（易碎地形 + 子泡探路 + 主动变小）
三城压力递进A 城潜伏教学（低压力 + 强引导），B 城能力升级（潜伏 + 谜题融合 + 阿基米德 + 权限），C 城剧情高潮（纪念碑矛盾 + 最终追逐全技能 call back + 信息交付结局）
用复用替代新机制传输节点替代早期的「加速管道」设计，直接 call back 信号塔的主泡注入——减少一次机制教学，也降低程序负担
道具需要时给信号干扰器在 A 城出口被追击时给，破解程序在 B 城中继站需要时给。不提前塞给玩家，避免出现「拿到却不知道该干嘛」的道具
剧情目标不过度引导用规则怪谈与环境信息给出目标，不做任务标记、不放 UI 箭头。让玩家觉得是自己发现的，而不是被指过去的
调性悲壮不绝望不是皆大欢喜，而是「使命完成，道路仍长」。探险派与保守派的矛盾被呈现但不被解决，结尾落在「探索从未止步」

十、开发节奏

1 个月原型期拆成 6 周，每周一个可验收的阶段目标。前两周是最高风险的「机制能不能玩」验证，后四周才进入内容生产——这个顺序是有意为之：先把玩法闭环跑通，再往上堆美术。

周次阶段具体内容
