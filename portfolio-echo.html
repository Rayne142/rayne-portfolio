ECHO（回声）—— 治愈叙事解谜游戏 Demo

2025年7月 项目架构报告 治愈系 · 双线叙事 · AI NPC

一、项目概述

游戏名称 ECHO（代号：回声）
游戏类型 2D 治愈叙事解谜游戏
开发引擎 Godot 4.6
美术风格 2D 叙事插画风
目标平台 Windows / macOS / Linux
开发周期 约 16 周（4 阶段）

核心概念

设计哲学

"让玩家在 90% 的游戏时间里，以为自己在被两个人爱着；在最后 10%，才发现从头到尾，都是自己在一个人的时空里，爱着不同阶段的自己。"

ECHO 是一款治愈系 2D 叙事解谜游戏，通过双线叙事（现实/梦境）和独特的"回声"机制，为玩家提供情感治愈的体验。

游戏的核心体验围绕"双时空压力转化循环"展开：

  • 现实线：玩家承接导师的期待，产生"被相信的温暖 + 怕辜负的压力"
  • 压力碎片：作为门票进入梦境线，在隐喻场景中解构压力
  • 梦境线：在隐喻场景中解谜，净化压力碎片
  • 最终揭示："导师 = 未来的自己"这一核心转折

二、NPC 系统详解（核心设计）

ECHO 的 NPC 系统是其最核心的设计亮点之一。系统采用AI 驱动的动态对话与人格演进机制，让每个 NPC 都具有独特的个性和成长轨迹。

2.1 双轨事件系统

NPC 与玩家的互动分为两种事件类型，分别对应不同的叙事功能：

维度 场景事件 (Scene Event) 聊天事件 (Chat Event)
触发方式 主控进入特定场景自动触发 NPC 主动发起或玩家自由发消息
对话模式 固定文案主导 + 关键节点自由输入 LLM 动态生成主导 + topic 框定范围
自由度 低（固定交谈结构） 高（主控可自由输入）
叙事功能 推进主线/支线剧情 延续、补充和深化场景事件中建立的关系

2.2 人设演进层级

NPC 会根据与玩家的互动深度，逐步展露不同层次的人格面向。这一设计让玩家感受到 NPC 是一个真实成长的个体，而非固定的对话树。

层级 名称 触发条件 NPC 表现变化
Lv.0 初识 未有任何事件互动 NPC 对主控态度中性
Lv.1 熟悉 完成 ≥1 个场景事件 主动发起频率提升，个性化称呼
Lv.2 信任 完成 ≥3 个场景事件 主动分享更多个人想法
Lv.3 共鸣 完成全部序章主线 NPC 事件 解锁隐藏台词和特殊场景反应

2.3 序章 NPC 角色设计

游戏序章设计了 3 个核心 NPC 角色，每个角色都有独特的身份、性格和语言风格：

江老师（01）—— 青年导师

核心特征：干练、直接、高效；温和而笃定的注视

关键台词："你可以做到，不是因为我说了算，而是因为你自己本来就做得到"

设计意图：代表"未来的自己"对"现在的自己"的信任和期待，是游戏核心转折的关键角色。

同学（02）—— 同年级同学

核心特征：真实、焦虑、有行动力但也会抱怨

关键台词："你一直都挺清楚自己要什么的。不像我，还稀里糊涂的"

设计意图：作为玩家的"镜像"，反映普通大学生的焦虑与迷茫，与主控形成对比。

室友（03）—— 合租室友

核心特征：务实、计划型、不多说废话

关键台词："你呢？这学期还是留在学校吗？"

设计意图：提供日常生活的真实感，通过碎片化对话展现室友关系的松弛与温暖。

2.4 AI 对话系统架构（概念层）

ECHO 的 AI 对话系统采用神经中枢架构，确保所有 AI 对话的可控性、可调试性和叙事一致性。

EchoNeuralHub（神经中枢）

所有 AI 对话的唯一执行主语，采用五阶段回合流程：

阶段 名称 操作 输出
1 PREPARE 收集对话上下文（玩家状态 + 记忆系统） 对话上下文
2 TURN-PROMPT 注入人格描述和当前回合动态信息 完整 Prompt
3 INVOKE 调用云端 AI 服务（流式输出） LLM 响应
4 INTERPRET 三态路由解析 解析结果
5 COMMIT 投影到对话 UI（对话气泡/情绪标签） UI 更新

PersonaSpec（人格说明书）

定义 AI 角色的可插拔人格单元，每个 NPC 都有独立的人格说明书，包含：

  • 人格描述：定义角色的语言风格、性格特征、禁止事项
  • 动态状态注入：根据情绪/关系值调整对话风格
  • 回复格式解析：确保 AI 回复符合预设格式

导师人格设计示例：

  • 语言风格：成熟、温暖、隐含期待
  • 禁止：儿语、过于直白的安慰、说教式语气
  • 关键词库：呼应叙事核心，被成年人的语气和逻辑所承载
  • 每次回复限 1 句话，不描述动作（微信聊天模式）

对话引导与意图判定

当玩家自由输入时，系统会先进行意图分类，根据偏离程度决定处理方式：

判定结果 定义 处理方式
相关（顺向） 与当前 topic 高度吻合 LLM 自然续接，正向推进
相关（侧向） 在世界观范围内但不完全符合预设 LLM 灵活接收，轻柔引导回预设方向
无关（低度偏离） 关联度低但无恶意 NPC 轻微反应后重新导向话题
无关（高度偏离） 完全脱离世界观 NPC 表现明显异样感，引导玩家重新参与

2.5 记忆系统

记忆系统是 AI NPC 具有"长期陪伴感"的关键，管理三类记忆：

记忆类型 容量 功能
工作记忆 窗口 = 20 条 用于 AI 对话上下文，保持短期记忆连贯性
长期记忆 上限 500 条 按重要性排序，NPC 可以"记住"玩家之前的选择
共享记忆碎片 双线共享 现实线与梦境线之间的记忆桥梁

关键功能：

  • 相似度查询：避免重复记录相似记忆
  • 记忆加锁：关键剧情记忆不可遗忘

三、游戏系统设计

3.1 双时空压力转化循环

这是游戏的核心机制，将玩家的现实压力转化为可交互的游戏循环：

循环流程

  1. 玩家在现实线中承接导师的期待 → 产生压力碎片
  2. 压力碎片作为"门票" → 进入梦境线
  3. 在梦境线中完成解谜 → 净化压力碎片
  4. 净化后的碎片转化为"回声" → 回复精力和认知进度
  5. 回到现实线 → 次日对话选项更新，叙事推进

3.2 压力值系统

属性设定
数值范围0-100，初始值 20
获得特点渠道少、数值小、积累慢
阈值触发40 解锁梦境、70 特殊对话、90 强制梦境
减少方式普通关卡 -25、隐藏关卡 -40、核心噩梦 -60、徽章额外 -10

3.3 精力值系统

属性设定
数值范围0-100，初始值 80
消耗特点白天行动的资源，消耗快、回复渠道多
三级状态精神(41-100)、疲惫(11-40)、透支(0-10)
回复方式吃饭 +5、午休 +20、普通睡觉 +40、梦境关卡 +50

3.4 经济系统（"窝囊费"）

真实复刻大学生"月光族"的经济状态，通过"窝囊费"这一货币体系，制造轻度的、可化解的财务压力。

类型项目金额触发时间
固定收入父母生活费1500 窝囊费每月 1 号自动到账
固定支出饭卡充值800 窝囊费每月 5 号自动扣除
可支配剩余可支配700 窝囊费/月用于社交、娱乐、突发消费

四、关卡与场景设计

4.1 镜屋关卡（核心关卡）

镜屋关卡是梦境线的核心关卡，分为三个阶段，对应"自我认知"的主题：

阶段一：镜子循环

玩家面对多面镜子，每面镜子对应不同年龄段的自己（三岁、八岁、十四岁、现在的自己）。核心机制为"选择消耗"：每面非目标镜被选两次后破碎消失，直至玩家找到目标镜"八岁的你"并触发对视。

阶段二：碎片收集与拼图

玩家收集镜子碎片，每块碎片触发对应年龄段的回忆闪回，最终拼合碎片修复镜面，引出小登。

阶段三：最终对话

与小登进行 LLM 对话，完成交流后获得铜硬币（苹果徽章）。

4.2 现实线场景（Day1）

Day1 是游戏的序章，建立玩家与导师、同学、室友的关系：

顺序阶段描述
1序章（苹果寓言）开场动画，苹果意象埋下伏笔
2白天·校园大地图自由探索，可触发食堂和宿舍事件
3食堂事件 + 宿舍事件并行事件，均可独立触发
4旧导师 Dale 发微信微信聊天事件
5新导师 Soren 微信微信聊天事件
6图书馆多轮选项图书馆学习场景
7深夜宿舍 + Soren 任务夜晚场景，Day1 完成

五、设计哲学与最高原则

情感优先原则

游戏的所有设计决策都应以"是否增强情感共鸣"为第一判断标准。谜题难度、叙事节奏、视觉表现、音效设计都服务于情感体验，而非单纯的游戏性。

双线叙事一致性原则

现实线与梦境线虽有明确分界，但必须在主题、情感线索、角色成长上保持内在一致性。两条叙事线不是孤立的，而是通过"回声"机制相互映射和呼应。

5.1 叙事引擎（黑盒设计）

叙事引擎是对外黑盒，内部计算认知进度：

认知进度 =

  • 梦境完成数 × 0.15
  • + 语言呼应次数 × 0.10
  • + 共享记忆对齐 ? 0.20 : 0
  • + 镜面时刻已触发 ? 0.30 : 0

当认知进度 ≥ 0.85 时，触发最终揭示。

六、设计总结

ECHO 的核心创新在于：

  1. AI NPC 系统：通过神经中枢架构和人格说明书，实现可控、可调试、具有长期记忆的 AI 对话体验。
  2. 双线叙事设计：现实线与梦境线的相互映射，让"压力转化"成为情感治愈的核心机制。
  3. 人设演进系统：NPC 会根据与玩家的互动深度展现不同的人格面向，让玩家感受到真实的成长关系。
  4. 叙事引擎黑盒：通过认知进度计算，确保叙事揭示的时机精准、有力。

项目严格遵循情感优先原则，所有系统设计都服务于"让玩家在游戏结束后，依然能感受到被理解和被陪伴"这一核心体验目标。
